## 재발 방지 게이트

- `tests/verify-all-windows-v22.py`는 4개 뷰포트 각각에서 주요 20개 이상 화면/상태를 실제 Chromium으로 열고 PNG를 저장한다.
- 404 리소스, 브라우저 JS 오류, 본문 가로 넘침, 주요 팝업 화면 밖 잘림을 실패로 판정한다.
- 2.2.0이 이미 로드되었을 때 업데이트 안내는 숨김. 임의의 2.3.0 응답에서는 실제로 게임시작 영역 아래에 표시되는지 검사한 후 숨김 복귀 검사.
- GO 연출은 타이머 잠금/재개를 유지하되 로직·보상·저장 데이터 자체는 변경하지 않는다.
- 현재 픽셀 디자인 만족도는 자동 QA만으로 확정 불가. 삼성 인터넷 실기기 재확인 필수.
- 실제 검사가 통과하고 육안으로 스크린샷을 검사하기 전까지 변경 브랜치를 Draft PR로 유지한다.
- LIVE 배포는 별도 사용자 확인 후 실시. 미검증 PR의 자동 정식 반영 금지.

## 지식자산 규칙

- 기존 승인 WebP/PNG 및 원본 소스 ZIP은 삭제하거나 덮어쓰지 않는다.
- 새 아이콘, 팝업 컷, 캐릭터 컷은 Figma LanyPang Asset Master에 명시적 개별 컴포넌트로 보유하고, 승인 후 WebP 분리 내보내기로 게임에 배치한다.
- SVG 아이콘 대체 또는 타 게임 UI/캐릭터 복제 금지.
- 아직 자체 개별 이미지로 만들어지지 않은 기능은 `보유 완료`라고 표기하지 않는다.
