# 카드빌 v0.6 — 누락 영어 전수 수정 감사

## v0.5 한글화가 불완전했던 이유

- `web/index.html`의 원본 `LEVELS` 배열 250개 `name`과 `theme`가 영문 상태였고, 뒤늦게 로드되는 화면 보정 스크립트에서 `lv.name`만 한국어로 덮어썼습니다. 250개 `theme`는 영어로 남았습니다. 모듈 간 실행 순서에 따라 영문 데이터가 외부에 노출될 수 있습니다.
- `web/js/multiplayer.js`의 방 연결·대기·연결 오류·상대 퇴장·차례 안내 및 기본 참가자명이 영어로 남아 있었습니다.
- `web/project-overlay/project.js`의 로컬 랭킹 안내에는 영문 기술 브랜드가 표시됐습니다.
- 오프라인 서비스워커는 구버전 캐시를 유지할 수 있었고, 자동검사는 표제·대표 버튼 중심이라 위 항목들을 감지하지 못했습니다.

## v0.6 실제 수정

1. **250개 레벨 이름과 지역(theme) 필드를 원본 레벨 데이터에 직접 한국어로 기록**했습니다. 각 레벨 번호·목표 점수·이동 횟수·색상·잠금·보스 메타데이터는 유지했습니다. `docs/STAGE_NAME_MIGRATION_v0.6.json`은 이전 이름 대조를 위한 개발 전용 기록입니다. 게임에 로드되지 않습니다.
2. 게임 실행 이후의 `lv.name` 덮어쓰기 코드 제거. 초기 게임·결과·지도 등 어디에서 읽어도 한국어입니다.
3. 2인 대전 연결 상태, 연결 실패, 방 대기, 참가자 대체 이름, 플레이 차례 및 방 코드 입력 설명을 한국어로 정리했습니다. 사용자 입력 닉네임, 자동 생성 코드, 기술 프로토콜 필드는 번역 대상이 아닙니다.
4. 로컬 랭킹 안내를 한국어만 사용하도록 수정했습니다. HTML 기본 언어와 PWA 이름·설명도 한국어로 유지합니다.
5. 서비스워커 캐시를 `cardville-match-v0.6-ko`로 버전 변경했습니다. 기존 진행 기록 저장 키는 유지해 업데이트 시 진행 데이터를 보존합니다.
6. `tools/check-korean-complete.cjs`를 새로 추가해 250개 레벨 데이터, 10개 지역명, 동적 2인 대전 문구, PWA 설명, 서비스워커 캐시를 검사합니다. GitHub Pages 및 Firebase 미리보기 배포의 실행 전 검사에 연결했습니다.
7. 격리 Chromium에서 **PC 1366×768, 모바일 390×844** 게임 진행, 클릭 2번 무반응, 마우스/터치 드래그 정상 점수 획득, 우클릭 메뉴 차단, 마지막 250단계 이름, 2인 대전·편집기·일일 도전·난이도 창의 한국어 표시 및 JavaScript 예외 0건을 확인했습니다.

## 범위와 남은 검증

- **게임 플레이 화면의 개발자가 통제하는 한국어 문구**를 대상으로 한 감사입니다. 내부 JS 변수·파일명·네트워크 메시지 타입과 공개 라이선스·개발 문서의 외국어까지 모두 제거하는 것은 아닙니다.
- 2인 대전은 아직 시험 기능입니다. 원거리 사용자 간 방 코드 매칭 가능 여부와 실제 서비스 품질은 이 한글화 검사로 입증되지 않습니다.
- 플레이어가 영어로 입력한 닉네임, 브라우저 자체 팝업, 외부 라이브러리 출력 및 이전에 캐시된 화면은 별도 요인이므로 100% 모든 환경에서 영어가 보이지 않는다고 단정하지 않습니다.
- `카드빌`은 기존 출시 중인 임시 게임명입니다. `라니팡 / Lany팡!`은 사용자 제안 단계로 확정 전이므로 이번 로컬라이제이션 수정에 임의로 섞지 않았습니다.
