# 라니팡 v1.2 — 캐릭터 모션 · 폭발 손맛 · 모바일 · 난이도 재조정

## 대상
- 실제 웹게임 GitHub 저장소 `junl-im/CardVille`, 기존 250단계/10지역 유지.
- 구버전 플레이 데이터 키 `sc_unlocked`, `sc_stars`, `sc_best`, `cv_last_level` 유지. 저장 데이터 초기화 코드 없음.

## 게임 난이도 보정
- 1~3단계: 4가지 동물 퍼즐, 18회 이동. 4~25단계: 5가지 동물 퍼즐, 18~22회 이동.
- 목표 점수: 1단계 650점, 5단계 1,550점, 10단계 2,700점, 25단계 4,650점.
- 9~10단계 잠금 블록 실제 1개/2개 지정. 초기 3색 + 30회 이동으로 발생한 의도치 않은 과잉 연쇄 억제.
- 자동 난이도 보정은 1~25단계의 설계 점수를 낮추지 않음. 26~250단계의 보수적인 기존 보정은 호환성상 유지.
- 3블록 기준 점수: 1연쇄 90점, 2연쇄 122점, 3연쇄 149점, 4연쇄 이상 180점. 연쇄 점수 배율 최대 2배.
- 콤보 발생 시 제한시간 추가 지급 폐지. 시간 모드와 일반 이동 횟수 모드는 계속 제공.

## 조작 및 디자인
- 드래그/스와이프만 게임 타일을 이동. 우클릭·클릭-클릭 스왑 금지 원칙 보존.
- 스왑 착지, 잘못된 스왑의 미세 흔들림, 새로운 타일 낙하, 표정 변형, 고연쇄 폭발 아트 반영.
- 이펙트 DOM 개수 최대 8개로 제한하고 24개 이하의 낙하 셀만 애니메이션.
- 모바일 팝업 탄성 등장과 작은 화면 스크롤/가독성 보강. 사용자의 모션 감소 설정 시 애니메이션 중단.
- PC의 자동 전체화면 요청 제거 및 버튼 숨김. 터치 포인터와 900px 이하 너비를 갖는 모바일에서만 버튼 노출.

## 성능과 검사
- 모바일 배경 파티클 50개에서 15개로 축소, 데스크톱 32개.
- 배경 파티클 최대 약 30fps로 갱신하고 탭이 숨겨지면 그리지 않음.
- 콤보 점수 HUD 이동 표시를 매번 재생성하지 않고 기존 DOM을 재사용.
- `tools/check-gameplay-v12.cjs`, 기본 `tools/check-release.cjs` 및 기존 UI 회귀 검사 모두 CI에서 실행.
- 실제 모바일 단말 프레임 타임/완료율/재도전율 계측 데이터는 아직 없음. 이후 초기 10단계의 첫 시도 성공률, 평균 사용 이동, 무이동 연쇄 길이를 측정해 추가로 균형 조정.

## 배포 주의
- GitHub Pages는 main push 시 검사 후 자동 업데이트.
- Firebase Hosting live는 별도 승인된 `ops/firebase-live-release.json` 배포 요청 변경 시에만 자동 업로드.
- Firebase Authentication, Firestore, Storage 등 사용자 서버 데이터는 이 업데이트 대상이 아님.
