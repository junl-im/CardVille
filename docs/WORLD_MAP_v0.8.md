# 라니팡 v0.8 — 지역 지도 · 스테이지 준비 · 결과 흐름

## 실제 구현
- 타이틀에서 `게임 시작`을 누르면 보드를 미리 생성하지 않고 **10개 지역 월드맵**이 열립니다. 각 지역 25개씩 총 250단계를 노출합니다.
- 숫자 스테이지 클릭 → 목표 점수·제한 이동·잠금 블록 수·최고 점수·현재 보유 도움 아이템 개수 확인 → `이 단계 시작`을 눌러 **그때 게임판을 초기화**합니다.
- 잠금 단계는 비활성화되며, 진행 기록 `sc_unlocked` `sc_best` `sc_stars` `cv_last_level`을 그대로 이용합니다. 별/아이템 수량을 임의로 늘리거나 재화를 차감하지 않습니다.
- 단계 승리 → 다음 단계 준비로 이동. 최종 250단계의 승리 → 지도 복귀. 패배 → 다시 도전 또는 모험 지도. 게임 중 지도 버튼으로 열면 퍼즐판은 그대로 유지되며, 새 단계 시작 시에만 재생성됩니다.
- 게임 중 Esc / 안드로이드 뒤로가기 시 메뉴 → 종료 확인, 준비창 뒤로가기 시 지도 복귀, 지도 뒤로가기 시 종료 확인. 일반 웹브라우저 자체 종료 불가, `나가기`는 타이틀로 안전하게 돌아갑니다.
- 스테이지 준비창 아이템은 **읽기 전용 표시**입니다. 유료 재화, 구매, 부스터 소비 등 미구현 기능을 작동하는 것처럼 꾸미지 않습니다.
- 배경은 v0.7 직접 제작 오리지널 일러스트를 재사용합니다. 상용 게임 IP의 캐릭터/게임 아트를 복사하지 않습니다.
- 로컬 저장 스키마 유지, 보드 드래그·스와이프와 우클릭 차단 유지, Firebase live 채널 미변경.
