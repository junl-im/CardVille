# 라니팡 v1.6: 실제 게임 내부 버튼별 전용 그림

## 범위
v1.5는 첫 화면에서 전용 토끼/고양이/책/도감 그림을 사용했고, 일반 게임 조작은 4종의 색상별 젤리 공통 배경을 사용했다. v1.6에서는 **기능마다 실제 독립된 일러스트 SVG 에셋**을 추가했다.

- 플레이·계속·이어서(Play/Resume): 직접 만든 삼각형 버튼/재개 기호
- 지도·처음 화면: 펼친 지도와 핀/작은 사탕마을 집
- 잠시 쉬기·나가기: 일시정지 표식/출입문 그림
- 재도전·다음 단계: 회전하는 화살표/별 트로피
- 도움말·동물 친구: 열린 책/돋보기 곰
- 뒤로·닫기: 방향 화살표/엑스

전체 자산: `web/assets/buttons/action-*.svg` 12개. 기존 버튼 배경 4종과 합성하되, 그림은 `::before` 레이어로 넣어 액션의 뜻을 인지하기 쉽도록 했다. HTML 안의 **텍스트 레이블은 남기고 중복 이모지만 제거**했다.

## 실제 구현
- `web/index.html`: 26개 게임 액션의 `data-lany-art` 할당, 기존 onclick 및 저장 로직 변경 없음.
- `web/css/lany-action-art-v16.css`: 컨텍스트별 아이콘 크기 및 간격, 모바일 320px, 620px 이하 짧은 화면 대응, 포커스/호버/터치 눌림 피드백, reduced-motion 대응.
- `web/sw.js`: 12개 신규 그림 및 CSS를 PWA 오프라인 프리캐시에 포함, 1.6 버전으로 캐시 갱신.
- `web/manifest.json`, `web/version.json`: 1.6 정식 버전 참조.
- 커다란 첫 화면의 1+3 구조, PWA 설치 기능, 250단계 및 저장 키, 타이핑/오른쪽 클릭 방지와 기존 퍼즐 기능 유지.

## 검증
- `tools/check-action-art-v16.cjs`: 에셋 및 26개 버튼 연결, 12종 CSS 규칙, SW 반영, 기존 클릭 이벤트 보존 검사.
- `tests/verify-action-art-v16.py`: Chromium 320×568 / 390×844 / 1366×768 / 320×440에서 지도/준비/일시정지/승리/실패 화면의 그림 표시, 실제 영역 잘림, 콘솔 오류 검사.
- GitHub Pages 및 Firebase preview/live CI 게이트에 정적 검사 추가. PR CI에서는 실제 브라우저 검사를 실행하고 주요 화면 스크린샷 업로드.

## 범위 제한
특수한 레벨 에디터, 시험용 난이도와 멀티플레이어의 내부 관리용 폼은 전용 그림 버튼으로 변경하지 않았다. 일반 게임 이용자가 자주 누르는 내비게이션·도전·결과·일시정지 버튼에 우선 적용했다.
