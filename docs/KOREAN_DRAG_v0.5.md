# CardVille v0.5 — 한국어·드래그 전용 기본 조작

- `html lang="ko"`, 문서 제목·HUD·부스터·승리/실패/튜토리얼·지도·250단계 이름 한국어 적용.
- 손가락 스와이프·PC 왼쪽 드래그가 퍼즐 교환 기본 방식. `pointercapture`, 12~22px 이동 문턱, 주축 방향 판단, 드래그 중 시각 피드백, 취소 복구.
- 두 칸 클릭 교환 금지. 일반 클릭은 아무 변화 없으며, **보조 아이템 대상 선택**은 버튼/탭 지원. 키보드 방향키+Enter는 접근성 별도 유지.
- 우클릭 컨텍스트 메뉴·HTML 기본 드래그·보통 텍스트 선택 게임 영역 차단. 입력칸 내 텍스트 선택은 허용.
- UI 영문 문구는 로컬라이즈, 게임 변수/저장 키/네트워크 프로토콜 영문은 호환성을 위해 변경하지 않음.
- 난이도/원격대전은 기존 플러그인 시험용이며 상용 완성 기능임을 주장하지 않음.
- `sweet-crush` MIT 원 저작권 문서 보존; 아이콘·사운드 외부 유료 자산은 허가 없이는 복사하지 않음.
