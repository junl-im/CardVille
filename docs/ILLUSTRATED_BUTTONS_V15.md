# 라니팡 v1.5 — 상용 캐주얼 퍼즐형 이미지 버튼

## 목표
기존 HTML 테두리 중심의 웹 느낌 대신, **라니팡 자체 동물 캐릭터와 캔디 젤리 아트**를 그린 전용 SVG 이미지 버튼을 사용한다.

## 첫 화면
- `title-logo.svg`: 통일된 라니팡 캔디 로고/동물 얼굴.
- `title-play.svg`: 큰 핑크/골드 메인 버튼 + 토끼/별. `#lany-start-button`의 기존 시작 이벤트 그대로 작동.
- `title-install.svg`: 파란 캐릭터 설치 버튼 + 휴대폰을 누르는 고양이. `#lany-install-button`의 PWA 설치 프롬프트와 iOS 안내 유지.
- `title-help.svg`: 노란 병아리 + 펼친 책. `LanyShell.openHelp()` 호출.
- `title-friends.svg`: 초록 곰 + 돋보기. `LanyFriends.open()` 호출.
- 메인 1개 아래 **한 줄 3개** 전용 그림 버튼, 시작 버튼과 별도 상하 간격.
- 이미 설치된 PWA에서는 설치 버튼 숨김 + 나머지 2개 중앙 정렬.
- PC 전용 전체화면 버튼은 계속 없음. 모바일 전체화면은 첫 화면이 아닌 **지도 상단**으로 이동.

## 실제 버튼 이미지 구조
`web/assets/buttons`에 전용 원본 SVG 5개(로고 포함)와 재사용 캔디 이미지 스킨 4색을 둔다. 로고/버튼 **배경과 캐릭터는 이미지를 그대로 화면에 표시**하고 글자만 접근성·반응형 가독성을 위해 HTML 텍스트 레이어로 유지한다. 따라서 클릭 영역과 원고 텍스트는 실제 `button`이며 이미지 자체는 `draggable=false`, `alt=""` 장식이다.

## 게임 내 버튼 스타일
- 핑크 / 파랑 / 골드 / 초록 4종 전용 `skin-*.svg`를 제작.
- 주요 지도·준비·팝업·페이지 이동·일반 게임 메뉴 버튼에 그림 배경 재사용.
- 레벨 원형 노드와 동물 타일은 고유 그래픽/작동을 유지.

## 조작 피드백
- 호버: `translateY(-4px)` + 살짝 커지고 밝아짐 (포인터 있는 PC).
- 클릭/터치: 짧게 아래로 눌리며 찌그러지는 젤리감, 원위치 복귀.
- 그림 버튼은 작은 별이 팡 튀는 시각 효과, 최대 7개 동시 생성.
- 지원되는 모바일은 짧은 진동(8ms), 재생모드나 브라우저가 지원하지 않으면 자동 생략.
- 키보드 Enter/Space 입력과 `focus-visible` 강조 지원.
- `prefers-reduced-motion` 사용자에게 애니메이션 제거.
- 기존 퍼즐 입력/배경 기록/250단계 데이터 수정 없음.
