# 라니팡 v2.3 디자인 자산 원본 관리

2026-10-15 신규 원본 이미지 시트 3종을 확보했다. 현재는 **적용 전 검수 후보**이며 기존 승인 WebP/PNG 및 기존 UI 구현을 우선한다.

## 확보한 시트

- `buttons_typography_sheet.png` — 버튼 상태, 이동·닫기 아이콘, 글씨색 및 대비 참고
- `region_maps_10_sheet.png` — 사탕 골짜기, 클로버 초원, 파도 만, 바람개비 언덕, 무지개 협곡, 달빛 숲, 쿠키 사막, 수정 빙하, 구름 호수, 별빛 항구
- `feature_decorations_sheet.png` — 오늘의 도전, 2인 대전, 친구 초대, 게임 방법, 앱 설치, 동물 도감, 난이도, 스테이지 편집기, 설정, 도움말, 마스코트 및 효과 장식

원본 3종은 별도 ZIP `LanyPang_v23_Asset_Source.zip`으로 로컬 보관했다. 해당 ZIP의 MANIFEST.json에 크기·SHA-256 기록이 있다. GitHub에는 원본 이미지 바이너리를 아직 업로드하지 않았다.

## 적용 전 필수 조건

1. 승인된 기존 캐릭터와 UI 래스터 자산을 유지하고 레거시 SVG로 회귀하지 않는다.
2. 각 이미지 시트에서 실제 필요한 부분만 추출하되 인접 이미지/레이블/프레임 오염을 확인한다.
3. 버튼 이미지에 그려진 한글은 정적 예시로 간주한다. 버튼 실사용 텍스트는 DOM 레이어로 구현하고 명도 대비 및 접근 가능한 이름을 확보한다.
4. 지역별 지도는 현재 게임의 지역 ID·스테이지 번호·잠금 상태·경로 좌표와 일치시킨다. 시트의 10개 지역은 디자인 후보이며 실제 월드 구조를 임의로 변경하지 않는다.
5. 320×440부터 모바일·PC 전체 화면을 캡처하여 지도 여백, 보드 잘림, 결과창 버튼 잘림, 설치 팝업 글씨색, 업데이트 안내 오탐을 재검증한다.
6. 실제 배포와 병합은 시각 QA와 회귀 테스트를 통과한 뒤에만 한다.

## v2.3 보완 적용 (2026-10-15)

- 기존 main에는 지도 월드 1·3·5의 WebP 원화, 지역 헤더, 도전·대전·초대·편집기 장식이 먼저 반영돼 있다. 중복 생성하지 않는다.
- 후속 패치: 기보유 install-ornament.webp와 friends-ornament.webp를 실제 설치·도감 제목에 연결하며 글씨색·포커스·비활성 상태를 통일한다.
- QA: 320×440, 320×568, 390×844, 1366×768에서 computed background 자산을 확인한다.
- 지도 원본 시트 10종을 라벨 없는 풍경으로 추출하여 5×2 WebP 아틀라스(world-atlas.webp)로 통합했다. 실제 게임 월드 10개 모두 아틀라스 내 독립 풍경을 사용하며 기존 지역 1·3·5의 개별 고화질 컷을 상단에 함께 유지한다. 그림의 테마를 기존 250단계 월드명에 맞춰 재배열했으며 지역명, 단계 번호, 경로 좌표는 변경하지 않았다.
- 기존 승인된 51개 WebP UI, 검은 고양이 및 동물 얼굴 30종, 저장 키를 유지한다. Firebase LIVE 배포는 하지 않는다.
