# 라니팡 v1.0 — 동물 얼굴 30종 · 모바일 반응형 UI

## 제공한 결과
- 토끼·곰·병아리·강아지·고양이·여우·늑대 등을 포함하는 같은 디자인 계열 동물 얼굴 30종. 기본 7종을 3매치 블록 이미지로 표시, 나머지 23종을 포함한 도감 제공.
- 모바일 화면 높이에 맞춰 퍼즐판 최대 크기를 제한하고, 30개 이동 점을 한 줄 막대로 단순화.
- 지도/동물 친구/일시정지 3개 버튼을 한 줄로 배치, 휴대전화 손가락 터치 우선.
- 게임 방법·단계 승리·실패·일시정지·단계 준비창·동물 도감·추가 기능 팝업을 safe-area/dvh 기준으로 조절. 화면보다 긴 내용은 팝업 내부 스크롤.
- 한국어 게임명 및 단계명 유지, 250단계와 보스 10종, 저장 키 변경 없음.

## 캐릭터 1차 아트 품질 범위
- 신규 생성 원본 캐릭터 콘셉트 보드에서 얼굴 부분을 추출하고 타원형 투명 마스크를 적용해 144x144 크기 PNG/WebP로 가공. 품질 검사 후 게임에서 WebP 사용.
- 단독 재그림 대신 원본 시트에서 분리한 1차 시안이므로 일부 가장자리·귀·톤은 추가 수작업 다듬기 필요. 디자인의 동일성을 높인 최종 정교화는 후속 단계.
